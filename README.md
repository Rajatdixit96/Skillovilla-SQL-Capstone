# Skillovilla SQL Capstone

SQL Capstone completed as part of Skillovilla training.

## Project Overview

This repository documents SQL problem-solving exercises completed during the Skillovilla SQL Capstone assessment. The assessment was completed live on the Skillovilla platform.

The original assessment did not provide a downloadable `.sql` project file. Therefore, the queries in this repository were reconstructed from the Skillovilla result screens and include the platform's displayed **Correct Answer** queries.

## SQL Topics Covered

- JOINs
- LEFT JOIN
- Aggregation with `COUNT()` and `SUM()`
- `GROUP BY`
- Date formatting with `TO_CHAR()`
- Common Table Expressions (CTEs)
- Window functions
- `RANK()`
- Subqueries
- Multi-table joins
- Quarterly sales analysis
- Ranking by sales and flight counts

## Capstone Questions

### 1. Tickets and Boarding Passes
Count tickets using the `tickets` and `boarding_passes` tables.

### 2. Booking Date Formatting
Represent `book_date` in `YYYY-MM-DD` format from the `bookings` table.

### 3. Most Popular Product by Store
Identify the most popular product in each store based on quantity sold.

### 4. Quarterly Store Sales Performance
Calculate quarterly sales for each store and rank stores within each quarter.

### 5. Airport Flight Ranking
Rank departure airports based on the number of departing flights.
